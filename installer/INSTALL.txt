IntegratedContro 설치 및 서버 설정

Windows 11 25H2 Pro·Enterprise / x64용입니다.
앱, ControlHost, MediaMTX 1.21.0, .NET 런타임과 LibVLC 영상 엔진을 함께 설치합니다.
.NET을 별도로 설치할 필요가 없습니다. 인터넷 없이 설치할 수 있습니다.

설치
1. 설치 프로그램을 실행하고 설치 폴더를 선택합니다.
   기본 위치: %LOCALAPPDATA%\Programs\IntegratedContro
2. 기존 원격 서버에 연결하거나 새 서버를 나중에 설정할 경우 첫 번째 서버 연결 항목을 유지합니다.
   같은 PC의 기존 서버를 연결하려면 두 번째 항목을 선택하고,
   host.json/control.sqlite가 있는 데이터 폴더와 기존 mediamtx.yml 파일, API 포트를 지정합니다.
   운영 데이터와 영상 서버 설정은 설치 폴더 밖의 별도 위치에 둡니다.
3. 바탕 화면 또는 시작 메뉴의 IntegratedContro를 실행합니다.
4. 새 PC에서는 로그인 화면의 접속 설정에 HTTPS 서버 주소와 인증서 SHA-256 지문을 입력합니다.
   로컬 서버 연결 설정을 선택했다면 접속 설정을 저장하고 앱을 다시 엽니다.
   앱이 꺼진 서버의 실행 여부를 물으면 확인 후 실행합니다.

기존 서버를 연결할 때
- 원래 데이터 폴더와 보호 파일을 유지하고 같은 Windows 계정으로 실행하세요.
- 설치 파일에는 기존 계정, 비밀번호, 인증서 개인 키, 장비 설정, DB가 들어 있지 않습니다.
- 기존 서버가 실행 중이면 자동 교체/종료하지 않습니다. 진행 작업을 확인한 뒤 정상 종료하고 전환하세요.
- MediaMTX가 실행 중이면 설치본과 실행 파일 경로가 달라 시작 확인에서 충돌을 표시할 수 있습니다.
  기존 영상 서버를 정상 종료한 뒤 설치된 앱에서 시작하거나, App\server-startup.json의 실행 파일 경로를 기존 서버로 지정하세요.
- DB/DPAPI를 다른 PC·Windows 계정에 복사하는 것만으로 인증서와 보호 비밀번호가 이전되지는 않습니다.

새 제어 서버를 처음 만들 때 (기존 데이터 폴더에는 실행하지 않음)
1. 운영 데이터를 둘 새 로컬 폴더를 정합니다. 예: C:\IntegratedControData
2. 설치 폴더에서 PowerShell을 열고 다음 명령을 실행합니다.
   .\ControlHost\IntegratedContro.ControlHost.exe setup --data "C:\IntegratedControData"
   안내에 따라 현장 이름, 관리자 계정과 12자 이상의 비밀번호를 입력합니다.
   비밀번호는 명령행 인수로 전달하지 않습니다. 완료 시 표시되는 인증서 지문을 보관합니다.
   기본 주소는 https://127.0.0.1:7443 입니다.
   다른 PC의 접속이 필요하면 관리자가 --bind <호스트 IP>와 방화벽/TLS 정책을 별도로 구성하세요.
3. Examples\mediamtx.example.yml을 데이터 폴더의 mediamtx.yml로 복사합니다.
   CHANGE_API_PASSWORD와 CHANGE_HLS_PASSWORD를 서로 다른 전용 비밀번호로 바꿉니다.
4. 같은 설치 파일을 다시 실행하고 '이 PC의 기존 서버 데이터 폴더 연결'을 선택합니다.
   방금 만든 데이터 폴더, mediamtx.yml, API 포트(예제: 9997)를 지정합니다.
5. 앱에서 HTTPS 주소와 인증서 지문을 저장한 뒤 다시 실행합니다.
   서버 실행에 동의하고 생성한 관리자 계정으로 로그인합니다.
6. 카메라 기능을 사용할 경우 관리자 → 사용 시작 → 카메라·영상 → MediaMTX에서
   API 주소(http://127.0.0.1:9997), HLS 주소(http://127.0.0.1:8888)와 각 계정을 설정합니다.

업데이트 / 제거
- 같은 설치 폴더의 앱과 서버를 정상 종료한 뒤 새 설치 EXE를 실행합니다.
- 기본 '기존 설정 유지'를 선택하면 App\server-startup.json과 접속 설정을 유지합니다.
- 기존 로컬 서버 연결을 다시 지정하면 이전 시작 설정은 server-startup.json.previous로 보관합니다.
- Windows 설정 → 앱 → 설치된 앱 → IntegratedContro에서 제거할 수 있습니다.
- 제거 시 운영 DB, 보호 파일, 접속 설정과 사용자가 만든 서버 시작 설정은 남겨 둡니다.
- 설치 및 제거는 서버·서비스·부팅 자동 실행·방화벽 규칙을 등록하거나 변경하지 않습니다.
