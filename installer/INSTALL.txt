IntegratedContro 설치 및 서버 설정

Windows 11 25H2 Pro·Enterprise / x64용입니다.
앱, ControlHost, MediaMTX 1.21.0, .NET 런타임과 LibVLC를 함께 설치합니다.
.NET 별도 설치와 설치 중 인터넷 연결은 필요하지 않습니다.

설치 및 최초 실행
1. 설치 프로그램에서 설치 폴더를 선택합니다.
   기본 위치: %LOCALAPPDATA%\Programs\IntegratedContro
2. 기본 '기존 설정 유지 / 원격 서버 사용 / 새 서버는 설치 후 설정'을 유지합니다.
   기존 로컬 데이터와 MediaMTX를 함께 지정하려면 두 번째 연결 항목을 사용할 수 있습니다.
3. 앱을 실행하고 로그인 화면의 '초기 설정 · 저장 위치'를 엽니다.
   신규 설치·기존 데이터·원격 서버·설정 오류 상태와 현재 저장 위치를 확인합니다.

새 제어 서버 만들기
1. '새 로컬 서버 만들기'를 선택합니다.
2. 운영 데이터 폴더를 선택합니다.
   기본 제안: %LOCALAPPDATA%\IntegratedContro\HostData
   설치 폴더와 겹치지 않는 다른 고정 로컬 디스크의 빈 폴더로 바꿀 수 있습니다.
3. 현장 이름, 관리자 아이디, 12자 이상 비밀번호와 확인을 입력합니다.
4. 수신 IP와 HTTPS 포트를 확인합니다. 기본 127.0.0.1:7443은 같은 PC 전용입니다.
   다른 PC도 접속하려면 실제 수신 IP 또는 0.0.0.0과 현장 네트워크 정책을 설정하세요.
5. '새 서버 생성 · 설정 저장'을 누르고 서버 실행에 동의한 후 관리자 계정으로 로그인합니다.
   기존 파일이 있는 폴더는 초기화하지 않습니다.

기존 로컬 데이터 연결 / 위치 변경
- 진행 작업을 확인하고 기존 호스트를 정상 종료하세요. 앱이 시작한 서버는 해당 앱을 닫으면 종료됩니다.
- 앱 재실행 시 서버 실행 질문에서 '아니요'를 선택합니다.
- '기존 로컬 데이터 연결 · 위치 변경'에서 host.json, control.sqlite와 인증서 파일이 있는 폴더를 선택합니다.
- 기존 계정과 이력을 유지하고 보호 인증서를 검증합니다. 원래 Windows 계정으로 실행하세요.
- 폴더 이전은 서버 종료 후 폴더 전체를 먼저 이전한 뒤 새 위치를 선택합니다. 앱은 파일을 이동하지 않습니다.
- DB/DPAPI 파일을 다른 PC·Windows 계정에 복사하는 것만으로 보호 정보가 이전되지는 않습니다.
- 실행 중인 서버는 자동 종료하거나 교체하지 않습니다.

원격 / 별도 서버 접속
- 서버 관리자가 제공한 HTTPS 주소와 인증서 SHA-256 지문을 저장합니다.
- 운영 데이터는 접속 서버에서 관리하며 이 PC에는 접속·화면 설정만 저장합니다.
- 이 방식은 로컬 서버 시작 확인을 끕니다. 기존 실행 서버를 종료하지 않습니다.

영상 서버 (카메라를 사용할 경우)
- Examples\mediamtx.example.yml을 운영 데이터 폴더 등 설치 밖에 복사하고,
  CHANGE_API_PASSWORD와 CHANGE_HLS_PASSWORD를 서로 다른 전용 비밀번호로 바꿉니다.
- 초기 설정의 '영상 서버 시작 설정'에서 실행 확인을 켜고 기존 설정 파일과 API 주소를 지정합니다.
- 앱의 관리자 → 사용 시작 → 카메라·영상 → MediaMTX에서 API/HLS 주소와 각 계정을 설정합니다.
- 다른 경로의 MediaMTX가 이미 실행 중이면 정상 종료 후 전환하거나 서버 시작 설정에서 해당 실행 파일을 지정하세요.

업데이트 / 제거 / 복구
- 같은 설치 폴더의 앱과 서버를 정상 종료한 뒤 새 설치 파일을 실행합니다.
- 사용자 설정: %LOCALAPPDATA%\IntegratedContro
  client.json: 접속 정보 / server-startup.json: 서버 시작 설정
- 기본 업데이트는 설정과 운영 데이터를 유지합니다. 연결을 명시적으로 재지정하면 이전 서버 설정은 .bak으로 남깁니다.
- 과거 App\server-startup.json은 사용자 설정이 없을 때 앱이 한 번 가져옵니다.
- 설정 오류는 초기 설정 화면에서 경로를 바로잡거나 서버 설정 백업을 복구합니다. 빈 DB로 대체하지 않습니다.
- Windows 앱 제거로 제품을 제거해도 운영 DB·보호 파일·사용자 설정은 남습니다.
- 서비스·부팅 자동 실행·방화벽 규칙은 자동 등록하지 않습니다.
