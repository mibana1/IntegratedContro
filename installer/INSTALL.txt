IntegratedContro 설치 및 서버 설정

Windows 11 25H2 Pro·Enterprise / x64용입니다.
앱, ControlHost, MediaMTX 1.21.0, .NET 런타임과 LibVLC를 함께 설치합니다.
.NET 별도 설치와 설치 중 인터넷 연결은 필요하지 않습니다.

설치 및 최초 실행
1. 설치 프로그램에서 설치 폴더를 선택합니다.
   기본 위치: %LOCALAPPDATA%\Programs\IntegratedContro
2. 시작 메뉴·바탕 화면 바로가기를 선택하고 설치합니다.
   데이터 폴더·서버 주소·영상 서버 설정은 설치 후 앱에서 지정합니다.
3. 완료 화면에서 기본 선택된 'IntegratedContro 실행'을 유지하고 마칩니다.
   첫 실행에는 '새로 시작 / 기존 서버 접속 / 기존 데이터 사용' 선택 화면이 열립니다.
   저장된 접속 설정이 있으면 기존 로그인 화면으로 이어집니다.
   실행 선택을 해제한 경우에는 나중에 바로가기 또는 설치 폴더의 App\IntegratedContro.App.exe로 실행하세요.
4. 데이터 연결이나 저장 위치를 바꾸려면 로그인 화면의 '초기 설정 · 저장 위치'를 엽니다.
   설정 오류도 이 화면에서 확인합니다. 연결 설정을 위해 다시 설치할 필요가 없습니다.

새 제어 서버 만들기
1. 앱의 초기 설정에서 '새로 시작'을 선택합니다.
2. 운영 데이터 폴더를 선택합니다.
   기본 제안: %LOCALAPPDATA%\IntegratedContro\HostData
   설치 폴더와 겹치지 않는 다른 고정 로컬 디스크의 빈 폴더로 바꿀 수 있습니다.
3. 현장 이름, 관리자 아이디, 12자 이상 비밀번호와 확인을 입력합니다.
4. 필요한 경우 '서버 수신 주소 · 고급 설정'을 엽니다. 기본 127.0.0.1:7443은 같은 PC 전용입니다.
   다른 PC도 접속하려면 실제 수신 IP 또는 0.0.0.0과 현장 네트워크 정책을 설정하세요.
5. '새로 시작 · 관리자 접속'을 누르고 서버 실행에 동의하면 입력한 관리자 계정으로 바로 접속합니다.
   기존 파일이 있는 폴더는 초기화하지 않습니다. 다음 실행부터는 비밀번호를 입력해 로그인합니다.

기존 로컬 데이터 연결 / 위치 변경
- 진행 작업을 확인하고 기존 호스트를 정상 종료하세요. 앱이 시작한 서버는 해당 앱을 닫으면 종료됩니다.
- 앱 재실행 시 서버 실행 질문이 나오면 '아니요'를 선택합니다.
- 앱의 초기 설정에서 '기존 데이터 사용'을 선택하고 host.json, control.sqlite와 인증서 파일이 있는 폴더를 선택합니다.
- '설정 저장 · 로그인으로'를 누른 뒤 기존 계정으로 로그인합니다.
- 기존 계정과 이력을 유지하고 보호 인증서를 검증합니다. 원래 Windows 계정으로 실행하세요.
- 폴더 이전은 서버 종료 후 폴더 전체를 먼저 이전한 뒤 새 위치를 선택합니다. 앱은 파일을 이동하지 않습니다.
- DB/DPAPI 파일을 다른 PC·Windows 계정에 복사하는 것만으로 보호 정보가 이전되지는 않습니다.
- 실행 중인 서버는 자동 종료하거나 교체하지 않습니다.

원격 / 별도 서버 접속
- 앱의 초기 설정에서 '기존 서버 접속'을 선택합니다.
- 서버 관리자가 제공한 HTTPS 주소와 인증서 SHA-256 지문을 저장하고 기존 계정으로 로그인합니다.
- 운영 데이터는 접속 서버에서 관리하며 이 PC에는 접속·화면 설정만 저장합니다.
- 이 방식은 로컬 서버 시작 확인을 끕니다. 기존 실행 서버를 종료하지 않습니다.

영상 서버 (카메라를 사용할 경우)
- 신규 설치는 '영상 서버 사용'과 '자동 생성 · 연결 확인 (이 PC)'이 기본 선택됩니다. 주소·계정·비밀번호를 직접 입력할 필요가 없습니다.
- 기존에 영상 사용을 꺼 둔 호스트는 앱을 정상 종료하고 다시 실행해 서버 시작 질문에 '아니요'를 선택합니다. 로그인 화면의 '초기 설정 · 저장 위치 → 기존 데이터 사용'에서 데이터 폴더를 유지한 채 '영상 서버 사용'을 켜고 저장합니다.
- 포트나 기존 파일 방식을 바꿀 때만 '영상 서버 · 고급 설정'을 펼칩니다.
  앱이 API/HLS 전용 비밀번호와 설정을 생성하고 인증 연결 확인 후 제어 서버에 등록합니다.
- 수동으로 준비한 서버는 '기존 설정 파일 사용'을 선택하고 관리자 → 사용 시작 → 카메라·영상 → 영상 서버 → 관리자 고급 설정에서 호스트 접속 정보를 설정합니다.
- 기존 로컬 서버에 영상을 추가할 때는 ControlHost·MediaMTX를 정상 종료한 뒤 설정하세요.
- 다른 경로의 MediaMTX가 이미 실행 중이면 정상 종료 후 전환하거나 기존 서버 설정을 유지하세요.

영상 비밀번호 변경 / 설정 재시도
- 자동 생성한 로컬 MediaMTX는 관리자 로그인 → 사용 시작 → 카메라·영상 → 영상 서버 → 관리자 고급 설정에서 비밀번호를 변경합니다.
- API/HLS 중 변경할 비밀번호만 입력하고 저장한 뒤 '적용 확인 · API/HLS 인증'을 실행합니다.
- 파일 적용이 중단되면 같은 변경을 다시 적용하거나 이전 설정으로 복구합니다. 서버 적용을 확인할 때까지 영상 처리가 일시 중지됩니다.
- 최초 설정이 중단돼도 이미 생성된 DB·계정을 다시 만들지 않습니다. 같은 폴더를 '기존 데이터 사용'으로 선택해 재시도합니다.
- 생성 파일이 외부에서 바뀌었거나 보호 파일을 읽을 수 없으면 원인을 확인하세요. 기존 폴더를 지우거나 새 현장으로 덮어쓰지 않습니다.

업데이트 / 제거 / 복구
- 같은 설치 폴더의 앱과 서버를 정상 종료한 뒤 새 설치 파일을 실행합니다.
- 사용자 설정: %LOCALAPPDATA%\IntegratedContro
  client.json: 접속 정보 / server-startup.json: 서버 시작 설정
- 설치 프로그램은 사용자 설정을 생성하거나 덮어쓰지 않습니다. 업데이트에도 설정과 운영 데이터를 유지합니다.
- 연결 변경과 설정 백업·복구는 앱에서 진행합니다. 과거 App\server-startup.json은 사용자 설정이 없을 때 앱이 한 번 가져옵니다.
- 설정 오류는 초기 설정 화면에서 경로를 바로잡거나 서버 설정 백업을 복구합니다. 빈 DB로 대체하지 않습니다.
- Windows 앱 제거로 제품을 제거해도 운영 DB·보호 파일·사용자 설정은 남습니다.
- 서비스·부팅 자동 실행·방화벽 규칙은 자동 등록하지 않습니다.

영상 설정 자동 사용
- 카메라·영상 화면은 접속한 호스트의 MediaMTX 설정을 자동으로 사용합니다. 다른 PC도 같은 ControlHost에 로그인하면 별도 영상 서버 정보를 입력할 필요가 없습니다.
- 영상 서버 탭에서 상태를 확인합니다. 비밀번호는 표시하거나 클라이언트 PC에 복제하지 않으며, 외부 서버 설정과 비밀번호 변경은 관리자 고급 설정에서 진행합니다.
